# ============================================
# Auto Name Tag - name list
# ============================================
# Location: .minecraft/mods/names.txt
#
# Format:
#   [entity_id] # mob name
#   Name 1
#   Name 2
#
# - Write one name per line
# - If a mob has several names, one is picked at random
# - Lines starting with # are comments (ignored)
# - Only mobs that have names listed here get named
#   (leave a mob without names if you don't want it named)
# - For mobs from other mods, use [modid:entity_id]
# - After editing, run /animalnamer reload in game to apply
#   without restarting (requires OP)
# - To always show names or to use special-effect names,
#   edit config/animalnamer.properties
#
# - The "Animal Guide" item (crafted from a book + wheat) lets you
#   browse and edit the names of every mob and change the settings
#
# In-game commands (require OP):
#   /animalnamer add <mob> <name>       add a name
#   /animalnamer remove <mob> <name>    remove a name
#   /animalnamer list [mob]             show registered names
#   /animalnamer nameall                name every unnamed mob in loaded chunks
#   /animalnamer showname on|off        always show names above mobs
#   /animalnamer special on|off         give special-effect names to all mobs
#   /animalnamer special chance <0-100> chance of a special name
# ============================================
