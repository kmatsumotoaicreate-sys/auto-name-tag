# ============================================
# Auto Name Tag - 名前設定ファイル
# ============================================
# 場所: .minecraft/mods/names.txt
#
# 書き方:
#   [エンティティID] # 日本語名
#   名前1
#   名前2
#
# ・名前は1行に1つ書いてください
# ・複数書くとランダムで選ばれます
# ・# で始まる行はコメントです（無視されます）
# ・名前を付けたくない動物は、名前を書かずにそのままにしてください
# ・ここに書いたIDのMOBだけに名前が付きます
#   （[zombie] のように書けば敵対MOBにも付きます）
# ・他のMODのMOBは [modid:entity_id] の形式で指定できます
# ・編集後はゲーム内で /animalnamer reload を実行すると
#   再起動なしで反映されます（OP権限が必要）
# ・名前を常に表示したい場合や、特別な効果のある名前を使いたい場合は
#   config/animalnamer.properties を編集してください
#
# ・アイテム「どうぶつ名鑑」（本 + 小麦でクラフト）を使うと、
#   MOBごとの名前の一覧を見たり、設定を変えたりできます
#
# ゲーム内コマンド（OP権限が必要）:
#   /animalnamer add <MOB> <名前>      名前を追加
#   /animalnamer remove <MOB> <名前>   名前を削除
#   /animalnamer list [MOB]            登録されている名前を表示
#   /animalnamer nameall               名前のないMOBにまとめて名前を付ける
#   /animalnamer showname on|off       名前の常時表示を切り替え
#   /animalnamer special on|off        特別な効果のある名前を全MOBに付ける
#   /animalnamer special chance <0-100> 特別な名前が付く確率
# ============================================
